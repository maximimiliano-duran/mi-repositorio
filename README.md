# Videojuego Unity

Repositorio limpio para iniciar desde cero un videojuego en Unity y C#. Las instrucciones y el alcance confirmado están en [AGENTS.md](AGENTS.md).

## Estado

Esta rama no contiene todavía un proyecto Unity ni assets. La cámara, el enfoque visual, la plataforma objetivo, los controles y el sistema elemental inicial están pendientes de decisión. No se ha descargado ni integrado ningún recurso.

## Primera muestra propuesta

Personaje controlable, ataque y habilidad de un elemento, esquive, una sala, un enemigo con patrón reconocible, vida y daño, derrota, recompensa con una mejora a elegir y reinicio del intento. No se añadirá progresión permanente tras morir hasta definirla.
