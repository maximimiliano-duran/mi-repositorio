# PrototipoElemental

Muestra técnica en Unity 6.3 LTS (`6000.3.28f1`) y C#, con Universal Render Pipeline. El proyecto usa combate 3D cenital y una dirección visual ilustrada en 2D. El nombre es técnico; el título comercial aún está pendiente.

## Estado

- Rama: `juego-unity`.
- Plataforma inicial: Windows PC.
- Monetización: aún no definida.
- Escena: plantilla Universal 3D de Unity. El combate no está implementado todavía.
- No se han integrado assets externos.
- La primera apertura del Editor espera que Maximiliano revise y acepte «Unity Editor Software Terms».

## Paquetes relevantes

- URP, Input System, uGUI/TextMeshPro y AI Navigation `2.0.16`: aportados por la plantilla.
- Cinemachine `3.1.7`: cámara.
- `com.unity.pipeline` `0.10.0-exp.1`: conexión local para automatizar el Editor; paquete experimental de desarrollo.

## Alcance de la muestra

Una sala con un personaje controlable, un ataque y una habilidad de un elemento, esquive, un enemigo, vida y daño, derrota, recompensa con elección y reinicio. El elemento inicial y la progresión permanente después de morir aún están pendientes.

Las decisiones y reglas del repositorio están en [AGENTS.md](AGENTS.md).
